# Officina XR (versione web)

Apri **https://flalessio21-hue.github.io/officina-xr-/** nel **browser del Meta Quest 3** e premi **ENTER VR**.

Spazio nero (o spazio profondo, sott'acqua, tramonto, aurora), scrivania in noce, la luce dell'AI che parla,
oggetti da creare, ingrandire, raggruppare ed esplodere fino all'ultima vite. Funziona con mani e controller.

Il codice completo (anche l'app nativa per il Quest) è nel repository privato `metaquest`.
